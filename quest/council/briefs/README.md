# Review briefs, verbatim

The instruction block that headed each review bundle, exactly as sent to every reviewer of that round. Bundles also contained the draft and evidence excerpts (not archived; reproducible from the commit each brief names). Numbering: 0x problem choice · 1x intent.md · 2x directive.md · 3x code review · 4x decision record + review example · 5x retro cold read · 6x handoff.md · 7x agents.md. The Opus reviewer received the same brief plus read-only repo access; the Codex and Kimi reviewers received only the bundle.
